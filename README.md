The actual code is in the "assembly" folder

Every year all the school has to do is upload a new "TCC.csv" and this seat planner will work.

By allowing staff to input the period and grade level, this program pulls class data, determines which students are affected, and organizes them into groups that fit within the auditorium’s capacity.

You have to use a formatted file for this to work. The file is selected when clicking the "upload" button in the program. There is an example file in this repository.
